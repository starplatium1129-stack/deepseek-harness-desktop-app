# 桌面用量统计

「用量统计」是工作空间与桌面管理之间的独立页面。覆盖今日、近 7 / 30 / 90 天的已确认消耗、活跃会话、缓存命中率、执行耗时、Token / 成本双轴趋势、模型分布和逐轮明细。支持模型筛选、点击时段筛选、标题搜索、最近活动 / 消耗 / 成本排序，以及打开原会话。

## 数据来源与口径

- 通过当前 Harness 的 `sessionQuery.listSessions` 和 `observeSession` 只读读取实时及历史会话；不直接解析上游压缩文件，不修改会话或凭据。
- 调用当前运行版本 `@deepseek-ai/dsh-token-meter/client` 的公开 `deriveTurnTokenUsage`。模型重试、缓存分类及不完整用量拒绝规则与上游本轮面板一致。
- 切除 `inheritedEventCount` 对应的分叉继承前缀，子 / 分叉会话的新增轮次单独列出。父子消耗不再次合并，避免双计。
- 已结束且具有完整用量的轮次计入总量，失败 / 中止的已知消耗也计入。进行中、未上报或数据不完整显示未知，已确认总数不能解释为账户全部消耗。
- 推理 token 是输出的子集；其他输入是总输入减去已知未缓存输入、缓存读取后的剩余量，包含缓存写入及未进一步拆分的输入。
- 缓存命中率统计缓存字段已知的轮次，分母仅包括同一批轮次的总输入；同时显示已知轮次覆盖数，存在未知轮次时注明“部分”。不把未知轮次计为零命中。
- 时间采用本机时区，已结束轮次按结束日期归属，跨日不拆分；进行中轮次按开始日期展示。耗时为已结束轮次墙钟时间之和，并行轮次分别计入。
- 混合模型轮次保留在“多模型（未拆分）”，不把整轮用量重复分摊给每个模型。标题搜索仅筛选明细，时间及模型筛选影响总览与图表；选中柱形后总览、模型及明细限定该日，趋势仍保留整个时间范围。
- 新增 Token 总成本（估算）、模型 / 会话 / 逐轮成本和按成本排序。上下文占用与订阅额度不属于本页统计。

## 价格同步与成本

价格设置提供两个来源：`https://models.dev/api.json` 与本机 `~/.cc-switch/model-pricing.json`（version 1）。首次运行检测到 cc-switch 文件时默认跟随它，否则选择在线模型库。只读取 cc-switch 文件，不修改其价格、同步设置或删除记录。在线自动同步间隔为 6 小时；本机文件每 30 秒检查修改时间，有变化才重新读取。可手动立即同步，也可关闭自动同步；应用未运行时不执行后台任务。

在线模型库保留提供方与模型的精确匹配，并为明确的原厂模型提供按 ID 匹配的参考价；不会从任意中转商选择最低价格。cc-switch 文件只有模型 ID，匹配时明确标注为模型参考价。同步成功后原子替换本地缓存；下载失败、格式不兼容或本机文件暂时不可读时继续使用旧缓存并提示。初次联网失败时仅有已核对的少量内置 DeepSeek 参考价。不同提供方、时段和长上下文阶梯的账单可能不同；包含不支持的复合计价字段的在线模型不会按单一费率导入。

优先级为桌面自定义单价、同步库的精确提供方匹配、同步库按模型 ID 的参考价、内置参考价。用户覆盖保存在 `usage-prices.json`，更新前保留 `.bak`；同步库保存在 `usage-price-catalog.json`，同步开关及来源保存在 `usage-price-sync.json`。同步不覆盖用户设置，移除自定义覆盖后恢复同步价 / 内置价。没有可用价时标为未计价，不能视作免费。

所有单价单位是 USD / 百万 tokens。分别计算未缓存输入、缓存读取、缓存写入及输出费用，推理不重复计费。内部用整数累计到万亿分之一美元，在显示时才舍入，避免大量微小费用被逐条舍掉。模型混用、未知用量、计费分类不完整或非零 token 对应的单价缺失时，该轮不估算，页面显示已计价覆盖率。所有历史按当前价格表重算，不是历史账单，也不还原高峰 / 低峰价格。

来源：[models.dev](https://models.dev/)、[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)。内置回退表核对日期为 2026-09-13，采用 DeepSeek 高峰参考价；同步库价格以库中的数值为准。

## 实现边界

`integrations/usage.cjs` 集中上游适配，`src/usage-model.js` 负责桌面筛选汇总，`src/usage-renderer.js` 负责展示。插件通过已有私有父子进程 IPC 回传有限的会话标题、身份和用量数字，不传正文、工具结果或模型凭据。常见密钥形式在标题回传前脱敏。桌面 IPC 仅接受本地管理窗口主 frame；会话跳转只接受最近读取快照中的会话 ID。插件浏览器部分使用 `uiWorkspace.openSession`，不向上游页面暴露桌面系统能力。

进入页面、手动刷新、页面内收到任务完成状态时读取；页面在前台时每分钟刷新。并发读取合并，读取失败保留上次结果并标明原因。每次最多读取 1000 个会话 / 20000 个轮次，超限或不可读数量在页面明确提示，不假装完整。读取有取消与超时控制，会话间让出事件循环。尚未建立跨启动的桌面独立索引，历史来自上游持久数据；大量历史的增量索引可作为后续性能改进。

## 0.2.4 Gemini 与缓存修复

- Gemini 官方条目带 `input_audio` 时，只要音频和文本输入单价相同，就保留可安全使用的统一 token 价格；不同单价或未知阶梯结构继续拒绝按平价导入。
- 对 `gemini-数字-flash/pro[-lite]-minimal/low/medium/high` 形式的路由模型名，在精确价格及用户覆盖不存在时回退至基础模型参考价，并显示匹配依据。不会随意去除 `fast`、区域或版本后缀。
- pi-ai 适配器省略零值缓存字段。桌面汇总前，仅当精确 `totalTokens` 等于已知输入、输出及缓存分项之和时，在只读副本中补充缺失的缓存零值，再交给上游逐轮汇总。不修改持久会话；剩余用量大于零时继续标记未知。
- 价格导入器带有修订标记，升级后自动同步会重新解析旧缓存；自动同步关闭时仍需手动点击同步。
- 2026-09-13 针对最近实际 `easycli-antigravity / gemini-3.8-flash-high` 会话进行只读验证：所检查 10 轮均自动计价、缓存字段均可确认，样本命中率 89.62%。这个数值只对应当时检查的样本，不代表账户全量。
- 49 项相关测试通过，0.2.4 Windows 分发目录通过包含双来源在线同步的界面验收。修复安装包为 `release/DeepSeek-Harness-Desktop-0.2.4-Setup.exe`；生成安装包不等于已升级当前运行中的应用。
