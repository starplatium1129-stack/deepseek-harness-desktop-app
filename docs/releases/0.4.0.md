# 0.4.0 · Windows 预览测试版

本次预览版增加可选择的玻璃外观、自定义壁纸、连续弹簧动效与完整的桌面键盘交互。内置 Harness 仍为 **0.1.5-rc.2**。

## 新增与改进

- 经典 / 玻璃预设，浅色 / 深色 / 跟随系统；本地图片、渐变和纯色背景，可调模糊及浅深色遮罩。图片副本保存在本机，移动原图不影响再次使用。
- 可打断、保留速度的弹簧动画，覆盖页面切换、按钮、导航指示器、侧栏与弹窗；玻璃边缘实际折射背景，配合高光与稳定的阅读表面。
- Ctrl+1～4 切页，Ctrl+, 打开外观，F6 在导航和内容间切换，F1 查看完整快捷键。原生右键编辑菜单和 Windows 窗口操作保持可用。
- 窄窗口布局、75%～200% 同步缩放，保存窗口位置、正常尺寸、最大化状态和缩放；恢复时避免窗口落在已移除的显示器上。
- 完善键盘焦点、Tab 循环、Esc 返回、重复打开弹窗与密钥保存失败后的输入保留；改善深浅色文字对比，响应强制颜色和减少动态效果偏好。
- 提供独立交互设计参考及源码。解压参考包后用 Chrome / Edge 打开 `index.html`，无需安装开发依赖。

## 下载与升级

- `DeepSeek-Harness-Desktop-0.4.0-Setup.exe`：Windows x64 安装包。
- `fluid-design-reference-0.4.0.zip`：独立演示、共享模块、设计说明和桌面交互参考示例。
- `SHA256SUMS-0.4.0.txt`：发布附件的 SHA-256 校验值。
- `0.4.0-build-info.json`：构建源码哈希、核心版本与提交信息。

先结束正在执行的任务并退出旧版，再安装升级。配置、会话和插件使用原有用户数据目录；外观和窗口偏好保存在独立文件中。外观切换本身不重启核心。

## 验证与预览版边界

- 本机 38 项相关自动测试通过，覆盖外观保存、弹簧与折射、窗口恢复、快捷键及原有统计和集成功能。
- 真实 Electron 与内置 Harness 的开发态和打包态检查通过，包含快速切页、侧栏与菜单、壁纸复制与重启恢复、键盘焦点、显示缩放、最大化状态恢复和原生编辑菜单模板。
- 布局检查覆盖 760×560 / 100%、1000×740 / 125%、760×560 / 200%、1440×980 / 100%。强制颜色与减少动态效果通过媒体模拟检查；折射有像素对照验证。
- **安装包未签名**；未完成无开发环境的全新 Windows 安装验收，也未完成物理多显示器、不同硬件 DPI 和真实读屏器验收。此次 UI 验证未使用模型凭据发送新的付费模型任务。
- 这是依据公开设计原则独立实现的 Web 材质与动效，并非苹果原生合成器或对 iOS 特定版本的逐帧复刻。上游布局适配当前针对 0.1.5-rc.2，不能保证未来版本自动兼容。
