# 0.4.1 · 外观修复

- 修复玻璃模式下工作空间设置面板挤在侧栏内、文字竖排的问题。滤镜直接作用于侧栏容器会改变内部 fixed 弹窗的包含块；现在由独立装饰子层绘制侧栏玻璃，弹窗继续相对视口定位。
- 经典与玻璃预设统一使用中性默认背景，取消开启玻璃时自动添加彩色渐变的行为。显式选择的渐变、纯色和壁纸继续保留，外观选项中的预设缩略图也改为中性色。
- 增加真实 Harness 设置布局回归检查，覆盖通用设置、模型、插件、Agent 预设、深浅色、减少动态效果、低效果模式及较窄窗口。

这是 0.4.0 预览版的针对性修复。安装包仍未签名，独立干净 Windows 机器与物理多显示器等验收边界不变。外观保存格式未改变，升级后保留已有配置。
