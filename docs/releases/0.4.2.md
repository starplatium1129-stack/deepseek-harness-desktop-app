# 0.4.2 · 主题同步修复

- 修复在工作空间设置里选择深色后，文字和控件已变暗色主题、桌面背景及玻璃层却仍保持浅色的问题。
- 桌面外观与工作空间内置的浅色、深色、跟随系统入口使用同一份保存状态。工作空间切换后立即重绘材质，并同步桌面外观控件、原生窗口主题与持久化偏好。

- 包含 0.4.1 的设置面板布局修复；默认背景恢复为普通模式原来的底色，玻璃只叠加材质。自选渐变、纯色和壁纸继续保留。
