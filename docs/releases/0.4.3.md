# 0.4.3 · 普通启动下的工作空间导航修复

这是本项目的最终社区版。项目已暂停独立维护，后续不再计划跟随上游持续发布桌面壳更新；如需长期使用或新功能，请优先等待并使用 DeepSeek 官方桌面版。

- 修复服务已就绪，但“工作空间 / 进入工作空间”点击无响应的问题。旧实现先等待隐藏 WebContentsView 处理截图动画，再显示目标视图；普通 Electron 启动的后台限流使这个等待可能无法完成。
- 导航现在先同步提交原生视图可见性、页面状态和焦点，再执行可选入场动画。动画失败或不返回都不会阻塞切页；不再在跨视图切页前截图或解码图片。
- 补充不使用 Playwright Electron loader 的原生启动回归，保留默认后台限流，直接检查原生 WebContentsView 的可见性。这个检查加入 Windows CI。
- 保留已有主题、默认背景、设置布局和用户数据。

安装包未签名；全新无开发环境 Windows 安装、真实 API Key 模型回复、未来上游版本兼容性和代码签名信誉仍未完成外部验收。具体范围见[验收记录](../validation.md)。

此前 Playwright Electron loader 自动添加了关闭后台限流等启动参数；它运行的程序文件与安装版一致，但运行条件不一致，导致之前的测试未能发现这个缺陷。之后分开记录自动化测试、普通启动和真实安装目录 / 现有数据的验收结果。
