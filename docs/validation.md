- 230 项 Node 回归测试通过 229 项，1 项因当前环境未连接实际 Codex 首次启动服务而跳过；无失败项。

## 0.1.0

环境：Windows 11 x64；Node 24.18.0；Electron 44.3.0；Harness 0.1.5-rc.1。

- Node 测试覆盖版本输入拒绝、日志脱敏、升级失败自动回退、成功升级后手动恢复、升级启动中断后的恢复、启动超时进程清理。
- 真实 Harness 首次启动通过认证返回 HTTP 200；第二次启动验证数据保留。
- Electron 开发态及打包态能够打开真实 Web UI，管理页可检查 npm 上游版本。
- 打包态测试从 PATH 中移除开发工具，验证由内置 Node 和 Harness 启动。此检查不等同于在全新 Windows 虚拟机上安装验收。
- 管理页面没有 Node require；上游页面没有桌面 IPC 桥接。
- 使用一次性旧版本状态触发真实 npm 下载，已验证 SHA-512 元数据检查、依赖安装、隔离认证试启动、应用更新及数据保留。此测试覆盖更新流程，不代表已验证不同上游版本间的全部功能兼容性。
- 仅对已确认退出的本应用子进程恢复其 PID 标记的残留锁，其他锁文件保留。
- 真实 Harness home 目录备份已验证，包含上游生成的 Windows 目录联接；相关回归测试已加入。
- 最终 NSIS 安装程序在本机静默安装退出码为 0，生成桌面与开始菜单快捷方式；安装后的可执行程序通过相同 UI 检查，模型配置入口正常显示。共 8 项 Node 回归测试通过。

未完成的外部验收：真实 API Key 模型回复、未来上游新版本的完整插件兼容性、全新 Windows 系统安装、代码签名信誉。当前未配置桌面壳自动更新渠道。

测试使用独立 `.test-data/`，不使用或修改用户的模型凭据及工作区。截图位于 `docs/screenshots/`。
