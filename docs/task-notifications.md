# 任务完成提醒

桌面运行的 Harness 每次主会话回合以 `completed` 结束时，顶部显示最近完成时间，并发送 Windows 系统通知。点击通知恢复窗口并打开工作空间；用户在工作空间中选择对应会话查看结果。系统关闭通知或开启免打扰时，顶部提示仍然保留。

通知不包含会话正文、标题、路径或凭据。失败、中止、工具步骤和子代理结束不触发完成通知；同一会话的同一回合只提醒一次。这里的完成表示 Harness 一轮执行正常结束，不代表代码已通过验收或已经合并。

适配依据为内置 Harness 0.1.5-rc.1 的 `session/event`、`turn/end`、`data.reason.kind` 和 `header.parentSession`。插件经私有父子进程 IPC 传递完成信号，桌面层显示通知，不修改上游 UI。升级核心时需复核这些事件字段。

本地开发修改插件后需运行 `npm run prepare:runtime` 更新运行资源；分发构建会自动执行此步骤。
