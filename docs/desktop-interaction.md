# Windows 桌面交互（0.4.0）

本阶段把外观之外的桌面行为补齐，沿用 Windows 原生窗口边框、系统菜单、最小化/最大化、Alt+F4 和原生文件选择器。

## 键盘与发现入口

顶部 `?` 或 F1 打开原生快捷键说明。仅在本应用获得键盘事件时处理快捷键，不注册系统全局热键，不记录输入内容。输入法合成、Alt/Meta 组合和未声明的按键交给系统或 Harness。

| 按键 | 行为 |
| --- | --- |
| Ctrl+1 / 2 / 3 / 4 | 工作空间 / 用量统计 / 桌面管理 / 外观 |
| Ctrl+, | 外观 |
| F6 / Shift+F6 | 导航与内容两个区域之间切换，包括独立的 Harness WebContentsView |
| 左右方向键 / Home / End | 在主导航内移动焦点；Enter 或 Space 激活 |
| Tab / Shift+Tab | 正向 / 反向访问控件 |
| Esc | 关闭页面弹窗并归还焦点 |
| Ctrl++ / Ctrl+- / Ctrl+0 | 两边同步放大 / 缩小 / 恢复 100% |
| Alt+F4 | 原生窗口关闭行为 |

正文前有键盘可见的“跳到内容”入口。主导航标明当前页与快捷键，单一 Tab 入口结合方向键导航。键盘切页会恢复该页之前可用的焦点，否则落在页面标题；后台状态刷新不会抢焦点。上游界面保留自己的内部快捷键，只截取上述桌面级组合。

页面模态弹窗打开时，桌面导航快捷键不切走当前表单。弹窗每次重新打开都重置上一次退出的几何状态，避免再次缩小；Tab 留在原生 dialog 内，关闭后恢复触发控件。密钥保存失败时保留输入以便修正，成功后清空，Enter 也可提交。保存期间禁用重复提交。

可编辑区域提供原生撤销、重做、剪切、复制、粘贴和全选菜单，按当前编辑能力禁用不可用项。普通选中文本提供复制、全选。

## 窗口、缩放与布局

`userData/window-state.json` 单独保存正常窗口边界、最大化状态和 75%–200% 的显示缩放。延迟合并保存，关闭时刷新，以临时文件替换避免半写入。可选窗口配置损坏或不可读时回到默认值，不阻断核心启动。

恢复前按显示器工作区限制尺寸和坐标：保留有效的负坐标副屏位置，副屏移除后回到当前可用工作区。主窗口默认最小 760×560；工作区比这更小时缩小最低限制。参考窗口也按可用工作区限制尺寸。

桌面和 Harness 同步缩放。独立 WebContentsView 的顶部偏移随缩放同步，避免遮住导航。窄窗口采用单列设置卡片、可换行工具栏和价格表单；装饰图与次要状态文字按空间收起，保留所有主导航和操作入口。长页面使用垂直滚动。

## 可读性与系统偏好

- 统计与配置正文使用稳定阅读底色。蓝色统计卡片、成本标签和图例分别使用适合深浅色的前景色。
- 输入框占位文字、状态说明和小号辅助文字使用统一的可读颜色；焦点环覆盖按钮、表单、摘要和可编程聚焦元素。
- Windows 强制颜色模式使用 Canvas / CanvasText / Highlight 等系统颜色，关闭壁纸、折射和阴影。高对比度偏好下也减少玻璃材质。
- “跟随系统”实时响应减少动态效果偏好，进行中的弹簧立即收敛；图片解码结束后再次检查减少动效，防止晚到快照重新启动动画。显式选择“完整动效”时以应用选择为准。
- 独立设计参考页初始跟随系统颜色与动态效果；用户切换后采用本次参考窗口的选择。

## 验证入口与边界

```powershell
node --test tests/desktop.test.cjs tests/fluid-design.test.cjs
node scripts/desktop-smoke.cjs
node scripts/desktop-smoke.cjs --packaged
node scripts/appearance-smoke.cjs --packaged
```

桌面测试使用 Electron 原生 `sendInputEvent` 路径验证桌面级快捷键，普通表单交互使用 Playwright。覆盖键盘切页、输入焦点恢复、保存失败保留输入、模态焦点循环、Esc、重复打开、F6 跨视图、编辑菜单模板、缩放与窗口重启恢复。

布局矩阵为 760×560 / 100%、1000×740 / 125%、760×560 / 200%、1440×980 / 100%，检查三个桌面页面及导航无横向溢出。缩放截图使用 Electron 原生 capturePage，避免 CDP 全页截图在页面缩放下裁切错误。

强制颜色与减少动态效果使用浏览器媒体模拟检查，尺寸和缩放通过真实 Electron 窗口执行。副屏移除的恢复计算有独立测试；未在物理多显示器、不同硬件 DPI、真实 Windows 屏幕阅读器或无开发环境的独立虚拟机上完成验收，不声称整款应用已达到某项无障碍认证。

## 0.4.3 导航验收修正

Playwright 的 Electron loader 会自动附加关闭后台限流等参数，因此不能单独证明普通快捷方式启动可用。新增 `npm run smoke:native-ui`，不使用该 loader、保留默认限流，并断言原生视图的实际可见性；同时仍需在实际安装目录与现有数据下，用原生窗口点击完成验收。跨视图导航不再等待截图动画。
